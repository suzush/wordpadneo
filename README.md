# English

## About

WordPad Neo is a project to provide a modern update to the original WordPad.

It aims to bring the classic text editor into the modern era with a refreshed look and feel, while maintaining the core functionality that users expect.

The project is currently under development, with ongoing work on core functionality, user interface improvements, and multilingual support.

## Project Goals

WordPad Neo aims to provide a modern text editing experience while preserving the simplicity and ease of use of the original WordPad.

Our main goals include:

- **Simple and Intuitive:** Provide an easy-to-use text editor for everyone.
- **Modern User Interface:** Create a refreshed design that fits modern desktop environments.
- **Familiar Experience:** Preserve the familiar workflow and usability of the original WordPad.
- **Multilingual Support:** Make WordPad Neo accessible to users around the world.
- **Community-Driven Development:** Encourage contributions and continuously improve the project through community feedback.

These are development goals; not all features have been implemented yet.

## Development Status

**🚧 WordPad Neo is currently a work in progress.**

The application is still under development, and its stability and completeness are not guaranteed.

Please keep the following in mind when using development versions:

- Some features may be missing, incomplete, or not working properly.
- Bugs and unexpected behavior may occur.
- Features and workflows may change in future updates.
- We recommend backing up important files before editing or saving them.

Development and improvements are ongoing.

## Contributing

Contributions to WordPad Neo are welcome. As the project is under active development, community contributions and feedback help shape its progress.

You can contribute in several ways:

1. **Code Contributions:** Improve existing functionality, fix bugs, or implement new features.
2. **Bug Reports:** Report unexpected behavior and provide steps to reproduce issues.
3. **Feature Suggestions:** Propose improvements that preserve WordPad's simplicity and usability.
4. **Documentation:** Improve explanations, instructions, and examples.
5. **Translation and Localization:** Improve interface text, messages, and documentation, or help support additional languages.

Please review existing Issues and Pull Requests before starting work. For contribution steps and guidelines, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Feedback and Bug Reports

If you encounter a bug or have an idea for a new feature, please share it through GitHub Issues.

Since WordPad Neo is still under development, some features may be incomplete or behave unexpectedly. Your feedback helps us improve the application.

## Join Us

WordPad Neo is dedicated to bringing the simplicity and familiarity of WordPad into the modern era.

Although the project is still in development, we hope to improve it step by step together with users and contributors from around the world. Every contribution, big or small, is welcome.

# 日本語

## このプロジェクトについて

WordPad Neoは、従来のWordPadを現代風にアップデートするプロジェクトです。

ユーザーが期待する中核的な機能はそのままに、デザインや操作感を刷新することで、この定番のテキストエディタを現代の環境に適応させることを目指しています。

現在は開発段階にあり、基本機能の実装やユーザーインターフェースの改善、多言語対応に向けた作業を進めています。

## プロジェクトの目標

WordPad Neoでは、従来のWordPadが持つシンプルさと使いやすさを大切にしながら、現代的なテキスト編集環境の実現を目指しています。

主な目標は以下のとおりです。

- **シンプルで直感的な操作性：** 誰でも簡単に使えるテキストエディタを目指します。
- **モダンなユーザーインターフェース：** 現代のデスクトップ環境に調和するデザインを追求します。
- **従来の操作感の継承：** WordPadに慣れ親しんだユーザーが違和感なく利用できることを重視します。
- **多言語対応：** より多くの地域のユーザーが利用できるよう、多言語化を推進します。
- **コミュニティによる開発：** ユーザーや開発者からの意見を取り入れ、継続的な改善を目指します。

これらはプロジェクトの開発目標であり、すべての機能が現時点で実装されているわけではありません。

## 開発状況

**🚧 WordPad Neoは現在、開発途中のプロジェクトです。**

現段階では、動作の安定性や機能の完成度を保証するものではありません。

開発中のバージョンを利用する場合は、以下の点にご注意ください。

- 一部の機能が未実装、または正常に動作しない可能性があります。
- バグや予期しない動作が発生する可能性があります。
- 今後の更新で、機能や操作方法が変更される可能性があります。
- ファイルの保存や編集を行う際は、重要なデータのバックアップを推奨します。

WordPad Neoは、今後も継続的に開発・改善を進めていく予定です。
