Privacy Policy

Last updated: November 7, 2026

This page is a publication draft. Verify the application's network behavior, diagnostics, and Windows AI features, and make sure this policy accurately reflects the distributed build before publishing.

1. Scope

This policy describes information handling in the WordPad Neo application and this project website. WordPad Neo is an independent open-source project developing a document editor for Windows.

2. Access to documents and purpose

The application may process documents users choose to open in order to display, edit, and save them and to provide user-requested functionality. Documents may contain personal information such as names and contact details. The purpose of processing such information is to provide document editing functionality.

3. Storage and control

Documents saved by the user are managed at the location the user selects. If documents are saved in a folder synchronized by OneDrive or another service, that service's settings and privacy policy govern synchronization. Refer to each release for details about autosave and temporary-file behavior.

4. Collection and transmission by the developer

The project's purpose is to provide document editing functionality, not to sell document contents or use them for advertising. Whether the released application includes developer-directed transmissions, diagnostics, third-party APIs, crash reporting, or AI-related features must be verified against the published build; this section must be revised if any such processing occurs.

5. This website

This site uses static HTML and CSS. It does not include first-party analytics, advertising trackers, custom cookie-setting scripts, or third-party web fonts. GitHub Pages, the hosting provider, may process connection data. Please refer to GitHub's Privacy Statement.

6. Third parties

Following links to external services such as GitHub subjects you to those services' policies. Microsoft Store and Windows handle data under Microsoft's applicable policies.

7. Retention, deletion, and contact

Users generally manage and delete their own saved document files. For privacy inquiries or requests, please use GitHub Issues. Do not post personal data or confidential documents in a public issue.

8. Updates

This policy may change as features, operations, or legal requirements evolve. Updates and the revision date will appear on this page.
