Support

Frequently asked questions

Is WordPad Neo finished?

No. It is actively being developed. Some features may be unavailable or unstable.

Where can I download it?

Check the GitHub repository and Releases page. A release may not be available yet.

Can I use it with important files?

Back up your files before editing or saving them in a development version.

How do I report a bug?

Search existing Issues first. Then provide steps to reproduce, expected and actual behavior, the app version, and your Windows version. Do not attach sensitive documents or personal data.

Contact & contributions

Report bugs, propose changes, and suggest translations through GitHub Issues. For code contributions, read CONTRIBUTING.md.
