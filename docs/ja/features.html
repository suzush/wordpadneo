開発版を利用する前に

  • 一部の機能は未実装・不完全である可能性があります。
  • 予期しない動作や不具合が生じる可能性があります。
  • 機能、仕様、画面構成は変更されることがあります。
  • 編集・保存前に重要なファイルをバックアップしてください。
