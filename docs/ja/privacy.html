プライバシーポリシー

最終更新日：2026年11月7日

1. 基本方針

WordPad Neoは、Windows向けのオープンソースの文書編集アプリケーションです。 WordPad Neoの開発者は、本アプリを通じてユーザーの個人情報を収集しません。 また、ユーザーの文書内容や利用状況を開発者のサーバーに送信することはありません。

2. 個人情報の収集について

WordPad Neoは、氏名、住所、メールアドレス、電話番号などの個人情報を 開発者が収集することを目的とした機能を備えていません。 また、広告目的の追跡やユーザーの行動分析も行いません。

3. 文書データの取り扱い

WordPad Neoは、ユーザーが指定した文書の表示、編集、保存のために 文書データへアクセスします。 文書に個人情報が含まれる場合でも、開発者がその内容を収集することはありません。

文書はユーザーが指定した保存先に保存されます。 OneDriveなどの同期対象フォルダーに保存した場合は、 該当サービスの設定およびプライバシーポリシーが適用されます。

4. 外部へのデータ送信

WordPad Neoは、ユーザーの個人情報や文書内容を 開発者が管理する外部サーバーに送信しません。 また、これらの情報を広告事業者などの第三者に販売・提供しません。

5. 本ウェブサイトについて

本ウェブサイトは静的なHTMLとCSSで構成されており、 独自のアクセス解析、広告トラッカー、Cookieによる追跡を行いません。 ただし、ホスティングサービスであるGitHub Pagesでは、 GitHubによって接続情報などが処理される場合があります。 詳細は GitHubのプライバシーステートメント をご確認ください。

6. 外部サービスについて

GitHub、Microsoft Store、Windowsなどの外部サービスによる 情報の取り扱いには、それぞれのサービスの プライバシーポリシーが適用されます。

7. お問い合わせ

プライバシーに関するご質問は、 GitHub Issues からお問い合わせください。 公開されるIssueには個人情報や機密情報を記載しないでください。

8. プライバシーポリシーの変更

本ポリシーは、アプリケーションの機能や運用の変更に応じて 改定される場合があります。 変更後の内容は本ページに掲載します。
